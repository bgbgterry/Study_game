# 🎮 國小四年級趣味學習闖關遊戲 (Study Game)

這是一個專為**國小四年級上學期**學生設計的互動式闖關測驗遊戲合集，支援 **3 種主題風格一鍵切換**（夢幻甜心風 💖、星際／深海勇者風 🚀、森林／溪流探險風 🍀）、挑戰者名字紀錄與 100% 滿分榮譽證書！

## 🌐 線上立即遊玩 (GitHub Pages)

1. **📖 [國語 1～6 課成語闖關大冒險 (點此遊玩)](./index.html)**
   - 收錄四上國語第 1～6 課共 **36 個核心成語**、**180 道分級題庫**（Level 1 ～ Level 5，每關 36 題，每次隨機抽 10 題）。
   - 內建「36 成語完整圖鑑」與即時解答成語小卡（注音、釋義、例句、近反義詞）。
2. **🔬 [自然「水生生物與環境」科學闖關大冒險 (點此遊玩)](./science.html)**
   - 收錄四上自然「水生生物與環境（活動 1 ～ 活動 3）」共 **36 張科學知識圖鑑卡**、**180 道分級題庫**（Level 1 ～ Level 5，每關 36 題，每次隨機抽 10 題）。
   - 內建「水生生物棲位與構造互動觀察箱」與即時科學原理、實驗觀察及必考陷阱解析。
